Tennis ML model

Four gradient-boosted models read the same pre-match features: statistics, astrology and numerology. Every retrain fine-tunes them: it tests which feature groups actually improve forecasts on the latest 12 months held out, tunes the settings, checks each recent season walk-forward against a plain Elo rating, then refits on all the data as a new version. Weekly on GitHub (Tuesdays), or on demand below.
