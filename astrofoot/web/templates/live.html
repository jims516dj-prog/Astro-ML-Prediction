Update now asks GitHub to run the forecast and results cycle immediately (new fixtures, finished matches), waits 2–3 minutes and downloads the outcome{% if not has_token %} — it needs a one-time GitHub token, see README → “Update now”{% endif %}. Get latest results just downloads what the scheduled runs (05:17, 11:17, 17:17 UTC) have already published. Either way, nothing new appears until the sources publish it: new fixtures and odds come from football-data.co.uk (usually refreshed Tuesday/Wednesday for midweek games and Friday for the weekend), with games it has not listed yet added from The Odds API within 30 hours of kickoff once its free key is set up. Its results can lag a day or more, so finished games are also looked up on football-data.org (top leagues, once its free key is set up) and ESPN's scoreboard (all leagues), usually within an hour of full time; football-data.co.uk later confirms or corrects them.
